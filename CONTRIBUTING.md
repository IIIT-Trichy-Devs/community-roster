# Contributing Guidelines

Thank you for contributing to the **IIIT-Trichy-Devs Community Roster**!

## Rules & Code of Conduct
1. **Valid JSON**: Ensure `members/batch-2026.json` remains valid JSON syntax (no trailing commas after the last object).
2. **One Entry Per Student**: Only add or update your own record. Do not modify or remove other students' entries.
3. **No Profanity or Fake Links**: Use your genuine GitHub profile URL.
4. **Branch Naming**: Use the pattern `add-<username>` or `update-<username>`.
5. **Commit Message Format**: Follow conventional commits (`feat: add <name> to batch-2026`).

## Pull Request Review
A community maintainer will review your Pull Request, verify JSON validity, and merge it into `main`. Once merged, your profile is officially part of the IIIT Trichy Devs alumni and student directory!
